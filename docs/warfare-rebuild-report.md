# 전면전 기본 데이터베이스 전환 결과 (2026-10-28)

## A. 수집 결과와 미완료 범위

- 전체 수집 총기: 0종. AR·SMG·LMG·DMR·SR·SG·권총 등 모든 분류 0종.
- 필수 수치 전체 확인 총기: 0종. 일부 수치 확인 총기: 0종.
- 정상 HTTPS 요청이 환경 프록시 CONNECT 단계에서 403 Forbidden으로 차단됐다. 문서 전체의 총기 존재, 분류, 이름, 기본 수치, 사격 모드, 시즌/게임 버전을 확인하지 못했다.
- 원문을 보지 못해 라이선스와 출처 표기 조건도 확인하지 못했다. 우회 수집과 다른 출처로 대체 수집은 하지 않았다.
- 따라서 나무위키 자료로 채워진 데이터베이스 구축은 아직 미완료다. 대상 출처와 실패 사유만 기록하고 총기를 임의 등록하지 않았다.

- 기존 샘플 데이터/도식, 장착·교체·해제·초기화, 호환성 엔진, 참고 합산/기여도와 추천 준비 엔진을 유지했다. 추천 알고리즘 변경·부착물 조사·신규 이미지 수집은 하지 않았다.
- `README.md`, `docs/data-sources.md`, `docs/manual-data.md`, `AGENTS.md`를 현재 상태에 맞췄다.

## C. 검증 결과

- `npm run build`, `npm run build:standalone`: 성공. TypeScript 검사와 정적 빌드/단일 HTML 생성 성공.
- `npm test`: 6개 파일, 37개 테스트 통과. 새 레코드 표시·영어/한국어 검색·숫자/null·모드·중복 및 기존 계산/호환성/추천 제한을 검사했다. 실제 데이터가 없는 테스트는 명확히 분리된 테스트 전용 가상 입력을 사용하며 앱에 포함하지 않는다.
- `npm run test:e2e`: 데스크톱/모바일 20개 통과(기능 검사 18개, 화면 캡처 2개). 빈 실제 자료 화면, 모드/로고 이동과 샘플 기능을 확인했다.
- 로컬 HTTP 서버에서 `npm run test:live`: 1440px/390px 모두 통과. HTTP 200, 이미지·장착·초기화·총기 변경·홈 복귀, 실제 미등록 상태, JavaScript 오류/가로 넘침을 검사했다.
- 배포 파일 HTML/JS/JSON/CSS에서 삭제 출처 문자열 및 이전 데이터 파일 참조가 없음을 확인했다.
- 실제 나무위키 총기 선택/수치 정확도는 자료가 없어서 검증할 수 없었다. 향후 등록 모델은 테스트 입력으로만 확인했다. 실제 휴대전화·Safari·Firefox는 이번에 검사하지 않았다.

## D. 다음 단계

정상 확인 가능한 나무위키 원문/표를 제공받거나 원문에 정상 접속할 수 있을 때, 라이선스/출처 조건과 전면전 여부를 확인한 기본 총기를 등록한다. 각 레코드는 observed로 시작하고 수집 불가 필드는 null로 둔다. 등록된 총기는 모드·게임 버전·기본 장비 조건을 맞춰 게임 내 직접 검증해야 한다. 그 후 별도 요청에서 준비된 슬롯·부품·호환성 모델에 부착물 자료를 추가한다.
