# 현재 데이터 출처와 검증 상태

사용자 요청에 따라 DFTTK에서 가져온 부착물·기본 수치와 관련 분석/관측 파일을 제거했다. 자동 수집이나 실시간 연동은 없다. 해당 자료를 명시적인 재요청 없이 다시 추가하지 않는다.

## 남아 있는 데이터

| 파일 | 출처/성격 | 범위 |
| --- | --- | --- |
| `src/data/sample.json` | 자체 제작 가상 샘플 | 가상 총기 3종, 부착물 13종 |
| `src/data/warfare_seed.json` | Aim Sector 기존 공개 기록, 확인일 2026-10-23 | 총기 이름 66종, AKM 기본값 1종, AKM 예시 부품 16개, 보정 사례 12건, 공개 코드 70개 |
| `src/data/weapon-images.json` | 사용자 이미지 등록 설정 | 현재 `{}`. 외부 사이트 이미지가 들어 있지 않음 |

M4A1은 Aim Sector의 이름·코드 목록에 남아 있지만, 기본 수치와 부착물 자료는 없다. 삭제한 수치를 0이나 샘플 숫자로 채우지 않는다. Aim Sector의 [총기 목록](https://www.aimsector.com/news/delta-force-loadouts)과 [AKM 예시](https://www.aimsector.com/news/delta-force-akm-build)는 별도 출처이므로 유지했다.

## 이미지와 데이터의 분리

작업대의 기본 이미지는 `WeaponArt.tsx`의 독자 제작 참고 도식이다. 총기 종류를 표현하며 특정 총기 실물/게임 모델의 정확한 재현이 아니다. 게임 수치의 근거로 사용하지 않는다. 직접 등록한 이미지가 있으면 이를 우선 표시하고 로딩 실패 시 참고 도식으로 돌아간다. 지원 도식이 없는 종류는 이미지 미등록으로 표시한다.

## 검증 상태

- `verified`: 동일 모드·버전의 실제 게임 검증 근거·검증일이 있어야 한다.
- `observed`: 공개 외부 자료에 있는 관측 기록. 게임 검증으로 승격하지 않는다.
- `unknown`: 미확인. `null`을 유지한다.
- `sample`: 가상 데이터. 실제 전면전 계산/추천에 섞지 않는다.

현재 남은 전면전 기록은 게임 내 미검증 상태다. `verified_weapon_base_partial`이라는 기존 JSON 키도 게임 검증 완료를 뜻하지 않는다. 실제 `game_verified` 값은 false다.

## 계산과 호환성 기반

기존 JSON을 `warfare-data.ts`가 정규화하고 `warfare-validation.ts`가 상태·참조·수치를 검사한다. `warfare.ts`는 기존 컴포넌트용 진입점이다. 삭제된 출처에 의존하던 수치 계산 테스트는 외부 자료가 아닌 테스트 전용 가상 입력으로 대체했다. 이 가상 입력은 앱 데이터에 포함되지 않는다.

AKM의 같은 공개 빌드에 함께 등장하는 부품은 관측 조합으로만 취급하고 다른 조합은 미확인으로 보류한다. 정밀 보정 사례는 기본 효과에 더하지 않는다. 추천 모델과 인터페이스는 유지하지만 검증된 게임 계산 전략/슬롯/수치가 부족하므로 실제 추천은 하지 않는다.

추후 자료 등록은 [직접 자료·이미지 넣기](manual-data.md)를 참고한다. 새 수치의 출처·단위·확인일을 기록하고 기존 자료와 구분해야 한다.
